## Findings

### Warning: Endpoint-Speed Search Is Narrowing But No Default-Safe Speedup Exists

Symptom: BD571 found a large wall upper bound but changed raw endpoint
observables; BD572 was clearly worse; BD573 preserved observables but did not
improve wall.

Source: A Philosophy of Software Design -- tactical local optimizations do not
solve the central design problem when the correctness proxy is weak.

Consequence: Continuing cap/slack-only phase-2 knobs would burn long-run time
without moving the default-safe endpoint blocker.

Remedy: Stop cap/slack-only phase2 PRs.  Either design a stronger selective
refined/coarse controller with an explicit local-error/observable proxy, or
return to payload/provider deflation where endpoint payload wall remains about
`834 s`.

### Warning: Deflation Worked In Production Code But Documentation Re-Inflated The Branch

Symptom: BD574-BD575 removed `610` net production lines, but the five-PR range
added `976` net documentation lines and `+366` tracked lines overall.

Source: The Pragmatic Programmer -- DRY and orthogonality apply to process
artifacts too; repeated long audit writeups can become another maintenance
surface.

Consequence: Even successful code deflation can fail the agent-efficiency goal
if every small deflation PR adds a long standalone document.

Remedy: For minor deflation-only PRs after BD576, prefer compact queue entries
unless a full endpoint run, failed long run, or physics decision requires a
standalone artifact.  Keep detailed standalone docs for endpoint/physics
evidence, not every helper-table cleanup.

### Suggestion: Trace Summary Deflation Should Continue Only While It Deletes Active Surface

Symptom: `augmented_ap65_trace_summary.py` now uses prefix tables for dynamic
payload, phase2, source, rejected-step, and host wall fields, but the larger
AP65 RHS and span-ladder monoliths remain the dominant analysis cost.

Source: Refactoring -- Extracting common logic is useful when it removes
duplication around active change points; beyond that it becomes churn.

Consequence: More table extraction in the same file may have diminishing
returns unless it deletes a large repeated block or unblocks endpoint work.

Remedy: BD577 may perform one more compact deflation only if it is clearly
net-negative and endpoint-relevant.  Otherwise switch back to endpoint runtime
work with same-recipe evidence.
