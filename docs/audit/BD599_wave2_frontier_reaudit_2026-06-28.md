## Remaining maturity (honest)

After Wave-2, the canonical FORWARD path remains the strong part: shear enters yields through the real coupled ODE (Hubble + bidirectional shear<->anisotropic-stress transport + live weak rates), the default backend='auto'/scipy is method-of-characteristics with no ell-truncation, FLRW is recovered cleanly at Sigma=0 without any monopole projection, and the jax_characteristic path matches SciPy to 1e-7 Yp / 1e-5 DH and captures 100% of the shear response. Wave-2 fixes the honesty surface but does NOT make the code publication-grade. Three structural blockers remain after Wave-2 and are explicitly OUT of scope for it (no new readiness gate, no publication claim): (1) BBN never identifies Sigma_H off-null with the current 2-observable (Yp,DH) likelihood — the Fisher is rank<=2 at every fiducial, so a data-driven Sigma_H constraint is mathematically impossible without a 3rd observable (Li7H wired into BBNPrediction + the predict callable); this is a structural ceiling, not deferred numerics. (2) The robust non-FD Sigma_H^2 Fisher that would defeat the even-response FD cancellation at the null is feasible (adjoint gives exact 0 gradient + exact Hessian on surrogates) but unbuildable because the BBN forward is not JAX-traceable (lax.while_loop + float() boundary in bbn_inference.py:73) and fisher.py hardcodes backend='fd'; realizing it is research-grade (~+50-150 net lines) and stays a tracked follow-on. (3) There is no posterior predictive check against real Aver/Cooke data; the null-recovery tests are self-consistent injection-recovery (circular). Net: Wave-2 yields an HONESTLY-LABELED forward+grid+FD-NUTS framework whose Sigma_H 'constraint' is correctly disclosed as prior/edge-dominated and whose backend labels no longer overstate shear fidelity — defensible as SPECIFIED/EXPLORATORY, not VALIDATED for a data-driven Sigma_H bound. Publication-grade additionally requires (beyond Wave-2): a 3rd observable to break the rank ceiling, a traceable forward to build the robust Fisher, and a real-data PPC.
